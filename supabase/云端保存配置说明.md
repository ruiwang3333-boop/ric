# 启用线上保存（Supabase）

GitHub Pages 提供网页托管，Supabase 提供登录和数据库。尚未配置 Supabase 时，本地记账仍可用，线上保存尚未启用。

## 1. 创建自己的项目

1. 打开 https://supabase.com/dashboard ，注册或登录。
2. 创建组织，然后选择 New project。填写项目名称、数据库密码和区域。数据库密码请自行保存在密码管理器中，不要填进网页或发到聊天里。
3. 等待项目创建完成。

## 2. 建表并启用权限保护

在项目左侧打开 SQL Editor → New query，粘贴同目录 `cloud-ledger.sql` 的全部内容，点击 Run。成功后会创建 personal_ledgers 表及保存函数，并通过行级权限限制每个账号只能读写自己的账本。

## 3. 配置邮箱登录

在 Authentication 的 Sign In / Providers 中确认 Email 已启用。如开启邮箱确认，新注册用户须先点击确认邮件再登录。
在 Authentication → URL Configuration 中，把 Site URL 设置为：

https://ruiwang3333-boop.github.io/ric/

确认邮件返回网页后，再点击“云端账本”登录。测试频繁发注册邮件可能触发平台限流，请按实际错误等待或配置自己的邮件服务。

## 4. 连接网页

在项目 Connect 或 Settings → API / API Keys 中取得 Project URL 和 Publishable key（或旧版 anon public key）。这是可放在前端的公开配置。不要使用 secret key、service_role key 或数据库密码。

打开记账网页 → 右上角“云端账本” → “连接自己的 Supabase 项目”，填写 URL 和公开密钥。注册自己的邮箱账号，完成邮箱确认，再登录。

公开配置在登录成功后保存在当前浏览器。在其他设备首次使用时也要填写同一项目的公开配置；可以后续将公开配置预填到网页中。密码和登录令牌仅保存在当前页面内存，刷新或关闭后需重新登录。

## 5. 保存与跨设备使用

- 本地记账仍自动保存。在线保存需要点击“保存到云端”，成功提示出现后才代表云端操作完成。
- 首次使用：在已有本地账目的设备登录 → 保存到云端。
- 换设备：连接同一个项目并登录同一邮箱 → 读取云端账本。
- 读取前请下载本地 JSON 备份；确认读取会替换当前本地账本。
- 多台设备使用：每次修改前先读取，修改后保存。网页会拒绝覆盖其他设备已更新的版本。遇到冲突，先备份本地记录，再读取云端，重新录入需要的变动。
- 不同邮箱账号有独立账本。本版不提供多人同时编辑同一份账本，也不会自动合并冲突。

## 验证范围

本地记账已通过 Chromium 浏览器测试。云端前端已用模拟响应验证登录、保存、跨设备读取、冲突保护、错误处理与数据校验。尚无真实 Supabase 项目，因此真实邮箱验证、SQL 执行和端到端云端持久化仍需在项目创建后验证；目前不能称为线上保存已启用。
